# UptimePulse 🚀

**UptimePulse** — это Fullstack-приложение для непрерывного мониторинга доступности веб-сайтов и API в реальном времени. Сервис автоматически проверяет заданные URL-адреса с определенным интервалом, фиксирует время ответа, коды статусов HTTP и собирает подробную историю логов.

Проект создан с упором на чистую архитектуру, строгую типизацию и современные DevOps-практики.

## 🛠 Стек технологий

- **Frontend:** React, TypeScript, Vite, Tailwind CSS / Shadcn UI
- **Backend:** Node.js, TypeScript, Express, Prisma ORM
- **Database:** PostgreSQL (Neon.tech Cloud)
- **DevOps & Infrastructure:** Docker, Docker Compose, Render (Backend deployment), Vercel (Frontend deployment)

## 📌 Ключевые фичи

- **Автоматический бэкграунд-воркер:** Фоновый процесс на Node.js, который пингует сайты по расписанию независимо от активности пользователей.
- **Интуитивный Fullstack API:** Эндпоинты для динамического добавления, удаления и просмотра целевых сервисов.
- **Подробное логирование:** Сохранение истории каждого запроса (HTTP-статус, время задержки в мс, тип ошибки при падении).
- **Docker-ready:** Архитектура полностью контейнеризирована и готова к запуску одной командой.

## 🗂 Архитектура базы данных (Prisma)

Проект использует реляционную модель данных в PostgreSQL:
- **Service:** Хранит конфигурацию мониторинга (URL, имя, интервал проверки, текущий статус `UP`/`DOWN`).
- **Log:** Хранит историю проверок. Связан с таблицей `Service` отношением один-ко-многим с каскадным удалением (`onDelete: Cascade`). Для оптимизации выборки по `serviceId` настроены индексы.

## 🚀 Быстрый запуск (Локально)

### Требования
- Установленный [Docker](https://docker.com) и `docker-compose`.

### Шаги для запуска
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd uptime-pulse
   ```

2. Создайте файл `.env` в корне проекта и добавьте строку подключения к вашей базе данных PostgreSQL:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/uptime_db?schema=public"
   ```

3. Запустите проект в Docker:
   ```bash
   docker-compose up --build
   ```

После сборки приложение будет доступно по адресу: `http://localhost:3000`.
